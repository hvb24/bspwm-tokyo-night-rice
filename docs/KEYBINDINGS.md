# Keybindings

Generated from `config/sxhkd/sxhkdrc` (press `super + F1` in the rice to see them live).

| Keys | Action |
|---|---|
| `super + Return` | Terminal (Alacritty) |
| `super + space` | Launcher: apps first, `Ctrl+Tab` cycles modes |
| `super + shift + a` | Fullscreen app grid |
| `alt + Tab` | Window switcher |
| `super + shift + space` | Run a shell command |
| `super + shift + f` | File browser |
| `super + e` | Thunar |
| `super + shift + b` | Browser (Firefox) |
| `super + shift + d` | Code editor (VS Code) |
| `super + shift + q` | Power menu (confirms logout, reboot, shutdown) |
| `super + shift + w` | Wallpaper picker (thumbnails) |
| `super + w` | Random wallpaper |
| `super + F1` | Show this keybinding list |
| `super + h/j/k/l` | Focus window in a direction |
| `super + shift + h/j/k/l` | Swap window in a direction |
| `super + 1..0` | Go to desktop 1-10 |
| `super + shift + 1..0` | Move window to desktop |
| `super + q` | Close window |
| `super + m` | Toggle monocle layout |
| `super + f` | Fullscreen |
| `super + s` / `super + t` | Floating / tiled |
| `super + ctrl + h/j/k/l` | Preselect split direction |
| `super + alt + h/j/k/l` | Resize window |
| `super + Left/Down/Up/Right` | Move a floating window |
| `super + alt + shift + q` / `r` | Quit / restart bspwm |
| `XF86AudioRaiseVolume` / `LowerVolume` / `Mute` | Volume |

Alacritty: `Ctrl+Shift+C/V` copy/paste, `Ctrl+Shift+N` new window in the same folder,
`Ctrl+Shift+O` toggle solid/translucent, `Ctrl+Shift+U` open a URL, `Ctrl+Shift+G` copy a git hash.
